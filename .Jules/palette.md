## 2025-05-14 - Contextual ARIA Labels for Generic Links
**Learning:** Screen reader users benefit significantly when generic link text like "Live Demo" or "View Details" is augmented with project-specific context. This helps users navigating by a list of links to understand each link's destination without needing to read the surrounding text.
**Action:** Always check for repeated generic link text in lists or cards and provide descriptive `aria-label` attributes that include the item's title.
